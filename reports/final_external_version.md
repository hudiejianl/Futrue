# Final External Version

## 1. 最终简历项目描述

**面向端边协同部署的刀具磨损监测与大模型辅助决策系统**

- 基于 QIT-CEMC 数据集完成力/扭矩、振动/声音、图像与磨损标签的清洗、对齐和结构化索引构建，形成可训练、可推理的数据资产
- 设计并实现 `Force-only` 主预测模型及多组多模态 baseline，对比分析不同模态在磨损回归、等级分类和系统解释中的作用，最终确定稳健主骨干
- 构建知识库、规则引擎与 DeepSeek(`deepseek-v4-flash`) 解释链路，实现刀具磨损状态诊断、风险评估与换刀建议生成
- 将主模型导出为 ONNX 并完成 CPU benchmark，结合 Gradio demo 构建可解释、可展示、可部署的工业智能原型系统

## 2. 最终三分钟介绍

我的项目是一个面向智能制造场景的刀具磨损监测与解释原型系统，使用的是公开的 QIT-CEMC Dataset。项目的目标不是单纯追求模型精度，而是完成“预测、解释、部署”三件事。

首先，在数据层，我对原始数据集进行了清洗和结构化处理，把力/扭矩、振动/声音、图像和磨损标签整理成可训练、可推理的样本索引。

其次，在模型层，我做了 `Force-only`、`Force+Vibration/Sound`、`Force+Image` 和三模态 baseline。实验结果表明，在当前数据质量和工程条件下，`Force-only` 是最稳、最强的主预测模型，因此我把它固定为主骨干，而把其他模态作为辅助信息源。

再次，在解释层，我没有停留在输出一个磨损值，而是构建了知识库、规则引擎和 DeepSeek(`deepseek-v4-flash`) 解释链路。系统会基于预测结果生成结构化摘要，再通过规则和知识库生成更自然的诊断报告和换刀建议。

最后，在部署层，我把主模型导出为 ONNX，并做了 CPU benchmark，证明它具备边缘部署可行性，同时还做了一个 Gradio demo 进行展示。

这个项目的价值在于，我完成的不是单个模型实验，而是一个从数据处理、模型预测、解释生成到部署验证的完整工业智能原型。

## 3. 最终一页总结

### 项目定位

不是单纯的多模态精度竞赛，而是一个：

- 可预测
- 可解释
- 可部署
- 可展示

的刀具磨损监测系统原型

### 最终技术主线

1. `Force-only` 作为稳定主预测模型
2. `Image` 和 `Vibration/Sound` 作为辅助模态
3. `DeepSeek` 负责诊断解释和建议生成
4. `ONNX` 支撑边缘部署验证

### 最终亮点

- 完成原始工业数据的结构化处理
- 做了多组 baseline 并形成清晰结论
- 接入 `deepseek-v4-flash` 并验证端到端报告生成
- 导出 ONNX 并完成 CPU benchmark
- 有 Gradio demo 和系统工作流文档

### 最终结论

当前项目最强的地方不是“多模态一定最强”，而是：

**它是一个比较完整、比较真实、比较可解释的工业智能系统原型。**
