# 项目经历

## 面向端边协同部署的刀具磨损监测与大模型辅助决策系统

`独立完成`

- 基于 QIT-CEMC 工业数据集完成力/扭矩、振动/声音、图像与磨损标签的清洗、对齐与结构化索引构建，形成可训练、可推理的数据资产
- 设计并实现 `Force-only` 主预测模型及多组多模态 baseline，对比分析不同模态在磨损回归、等级分类和系统解释中的作用，确定稳健主骨干
- 构建知识库、规则引擎与 DeepSeek(`deepseek-v4-flash`) 解释链路，实现刀具状态诊断、风险评估与换刀建议生成，并完成真实端到端调用验证
- 将主模型导出为 ONNX 并完成 CPU benchmark，结合 Gradio demo 构建可解释、可展示、可部署的工业智能原型系统

### 技术栈

`Python` `PyTorch` `Pandas` `ONNX` `ONNX Runtime` `DeepSeek` `Gradio` `SQLite/SQLite-like data processing` `NumPy`

### 项目亮点

- 完成从原始工业多模态数据到结构化训练样本、模型实验、解释生成、部署验证的完整闭环
- 在当前数据条件下，基于实验结果收敛出 `Force-only` 作为稳定主模型，并将多模态定位为辅助信息源
- 实现本地可运行的规则 + 知识库 + LLM 解释链路，提升了系统可解释性与演示效果
